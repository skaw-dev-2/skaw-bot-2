GUILD MEMBERS INTENT — INTEGRATION NOTE

File inisialisasi Client tidak disertakan dalam source yang tersedia saat patch ini dibuat, jadi tambahkan intent berikut secara aditif pada file Client yang sudah ada.

1. Pastikan GatewayIntentBits diimpor dari discord.js.
2. Tambahkan GatewayIntentBits.GuildMembers ke intents array yang sudah digunakan.
3. Discord Developer Portal > Application > Bot > Privileged Gateway Intents > enable Server Members Intent.

Contoh struktur (jangan mengganti intents existing; gabungkan satu baris intent saja):

const client = new Client({
    intents: [
        // intents yang sudah dimiliki project tetap dipertahankan
        GatewayIntentBits.GuildMembers,
    ],
});

Untuk atribusi siapa yang melakukan perubahan role, beri bot permission View Audit Log. Jika tidak tersedia, auto log tetap dapat terbit dengan Recorded by SKAW Bot.
